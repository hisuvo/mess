### Important Data Mode APIs
API                      	Purpose
createBrowserRouter ----	Create router
RouterProvider----------	Provide router
loader------------------	Fetch route data
action------------------	Handle mutations
useLoaderData-----------	Access loader data
useActionData-----------	Access action result
useNavigation-----------	Track navigation state
useFetcher--------------	Fetch or submit without navigation
Outlet------------------	Render nested routes
NavLink-----------------	Navigation with active state
useParams---------------	Access URL parameters
useRouteError-----------	Handle route errors
